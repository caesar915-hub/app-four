Meadow system — implementation deltas vs v4 notes

Mood palette migrationM2 replaces the shipped coral→blue palette in Recording+MoodDisplay.moodColor — the SSOT — so the calendar timeline, mood library, and detail views re-color automatically. One change, app-wide consistency.
Energy rampNew 5-step Palette.energyRamp (voltage blue). Existing single-color orange energy tags migrate to the ramp's mid step. Palette.warning stays orange — warnings and energy are no longer the same color, which is a small win.
Focus rampPalette.focusRamp built from dynamic colors (UIColor { trait in ... }) so the graphite ramp inverts automatically in light mode. Sleep tags keep indigo, now unshared.
Empty ≠ foggyAll empty states (beads, matrix cells, gauge tracks stay) use dashed strokeBorder instead of gray fill — graphite "foggy" is always a solid fill, "no data" is always an outline.
Med × focus connectionNew first connection card pairs medication days with focus levels — the single most valuable insight for an ADHD med journal. Purple appears exactly once, for meds, as everywhere else in the app.
CVD noteM2's red↔green axis is the classic deficiency pair — mitigated by monotonic luminance steps (low is much darker than great), level words always beside colors, and counts everywhere. Worth one VoiceOver/grayscale pass before TestFlight.
