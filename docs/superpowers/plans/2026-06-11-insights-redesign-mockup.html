SwiftUI mapping (for later — no code changes now)

Serif headersTypography gains a display role: .title.weight(.bold) + .fontDesign(.serif) → renders New York, scales with Dynamic Type, no font license needed. Left-aligned, replaces centered InsightsHeaderSection.
GradientsEach mood color gets a LinearGradient from a 12%-lightened variant to the base — derived in Recording+MoodDisplay, single source of truth stays put.
Stacked barsTimeOfDayBars renders one segment per mood bucket (% inside each segment) instead of dominant-color only. Empty bucket = var(--empty) track, no label.
Bubble breakdownReplaces MoodPieChart with overlapping circles sized by share (area-proportional). Legend stays.
AdaptiveEverything uses existing Theme tokens — both modes shown here. No dark-only fork.
A11y% labels inside bars are real text (Dynamic Type); blob counts have accessibilityLabel("Resting, 4 check-ins, mostly Okay"); color never the only signal (counts + labels everywhere).
