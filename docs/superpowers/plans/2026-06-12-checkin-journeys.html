Check-in customer journeys

Full flows to think through — two for voice (each shows prompts so you remember what to talk about) and two for text (pick mood / energy / focus / meds / sleep + write). Same hand-drawn language as v4. Light mode shown; each step is a screen.

→ arrows = a tap / transition. Scroll each row horizontally.

🎙 Voice check-in
V-A · Prompt checklist first, then speak freely
SEE THE QUESTIONS UP FRONT · RECORD ONE TAKE · AUTO-TAGGED ON REVIEW
From the hub you tap Speak check-in. Before recording you see a short "things to cover" card (mood, wins, meds, sleep, anything off). Tap start, talk through them in one take, then review the transcript with mood/energy/focus/meds/sleep already pulled out. Calm, low-pressure, you read the prompts before talking.
V-B · Guided — prompts appear one at a time while you talk
RECORD IMMEDIATELY · PROMPTS ROTATE IN THE RING · TAP NEXT OR LET THEM CYCLE
Tapping Speak check-in starts recording right away; a single question floats above the ring and advances ("How's your mood?" → "What got done?" → "Meds & sleep?"). Feels like a gentle interview — good when a blank mic is intimidating. Same auto-tagged review at the end.
✏️ Text check-in
T-A · One screen — tag & write together
MOOD / ENERGY / FOCUS / MEDS / SLEEP SELECTORS ON TOP · WRITE BELOW · SAVE
Tap Type note → a single composer: quick scales for mood, energy, focus, then meds & sleep chips, then a free-write box. Everything optional; tap Save when done. Fewest steps, everything visible at once (can feel dense).
T-B · Write first, tag after
BLANK PAGE TO WRITE · THEN A TAG SHEET FOR MOOD/ENERGY/FOCUS/MEDS/SLEEP
Tap Type note → a clean writing page (just you and the text). When you tap Done, a tag sheet slides up to optionally set mood / energy / focus / meds / sleep, then Save. Protects the writing moment; tagging is a deliberate second beat.
