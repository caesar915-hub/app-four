Check-in view — crescent hub

Three proposals replacing the old Record screen (segmented Voice/Text picker + waveform + round record button). Each is a single Check in hub built around your crescent sketch, with three actions: Medication → Log meds, Voice input → Speak check-in, Text input → Type note. Shown light + dark.

Colour is deliberately neutral here. Since the palette is being reworked, these use graphite ink + one placeholder accent so you judge form & interaction, not colour. Medication purple is the one fixed hue.  ·  The question each proposal answers differently: does the crescent stay decorative, or does it become the live recorder (replacing the deleted waveform)?
A · Faithful Hub
CRESCENT = DECORATIVE BRAND MOTIF · THREE EQUAL ACTIONS
Closest to your sketch. A static double-stroke crescent frames three equal-weight pills. Tapping any pill pushes to its own flow — Medication opens the existing log sheet, Voice opens a dedicated recording screen, Text opens the note editor. The hub itself does nothing but choose. Calmest, most literal, least surprising.

B · Living Crescent
CRESCENT = THE RECORDER · IN-PLACE TRANSFORM
The crescent earns its keep. At rest it shows the three pills (left). Tap Voice input and the pills recede — the crescent fills into a live audio ring that pulses to your voice, the timer + a stop button sit in its belly (right). This is what replaces the deleted waveform. Text and Medication still push to sheets; only Voice transforms the hub in place. Most distinctive, ties the brand shape to the core action.
