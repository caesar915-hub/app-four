Mood palettes — variations

Pick the mood first — it's the anchor, and it's already shipped (calendar + library use it), so the mood choice carries the most weight. Each concept is shown in three colour variations: ·1 base, ·2 soft (gentler, desaturated), ·3 bold (vivid, higher contrast). Variations are derived from the base in HSL, so each trio is the same mood "dialed." Med purple is shown on every card for context.

—

How to use this page

1. Find a mood you'd want to open every morning — scan the ·1 base column first, then check whether its ·2 soft or ·3 bold sibling reads better.
2. The two sliders retune every ·2 and ·3 live — push softness up for a calmer app, boldness up for a punchier one.
3. Each card shows headroom vs med purple — all moods here stay clear of purple, so energy + focus stay free to choose later.
4. Reply with a mood code (e.g. Coast ·3 or Tide ·2) and I'll lock it as the mood ramp, then bring back energy + focus options that pair clean with it.
