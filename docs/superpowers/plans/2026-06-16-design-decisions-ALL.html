1 Identity & posture FINAL

✓
"Paper & Pollen" — warm paper (light) / loam (dark), organic, calm + frictionless. Never pure white, never #000.
✓
Thesis: "A warm field journal that listens. Meadow as the skin, ruthless speed as the skeleton. The app is always slightly calmer than you."
✓
North star: effortless — in and out under a minute.
✓
Product: on-device, privacy-first ADHD voice check-in journal (iOS / SwiftUI). Audience is a functional constraint: low cognitive load, minimal friction.
✓
Posture (non-negotiable): glyphs not emoji faces · no gamification / streaks · meds never nag (no red, no "you're late") · privacy-first.

5 Spacing · layout · motion FINAL

✓
8px base. Scale 4·8·12·16·24·32·48. Radius: small 12 · medium 14–16 · card 18 · pill/full 999.
✓
One primary action per screen. Four tabs: Calendar · Check-in · Insights · Settings.
✓
Cards on Surface, hairline + soft shadow, reading order. Buttons: primary = Meadow gradient pill, secondary = ghost pill. Chips for feelings/side-effects/meds (tap × to remove, "+ Add").
Signal picker — tap 1→5 (current ringed)
✓
Crescent (CrescentRing): breathes idle (~5s, 1→1.035) → revolves while listening (~7s/rev) with a voice-level glow → settles to a check when saved.
✓
Easing: enter ease-out · exit ease-in · move ease-in-out. Durations: micro 50–100ms · short 150–250 · medium 250–400.
✓
No confetti, no streak celebration, no "you're late" alarms. Honor Reduce Motion (breathing → static glow).

6 Medication FINAL

✓
Purple #7E5CA8 — the one hue no signal uses. Horizontal capsule icon (single, two-tone).
✓
Bar fills empty (just taken) → full (worn off) over MedicationEvent.durationHours. One consistent purple — only the fill changes, so onset and fading never share a color.
✓
Onset (~first 20 min) shows a gentle pulse ("kicking in"). Worn-off → quiet, overlay fades out. Never alarms (no red, no nag).
✓
Med overlay rides above Check-in when a dose is on board. Fuller effect curve (rise → peak → decline) may show in the med card where there's room.

7 Screens — every state FINAL

Calendar timeline

Check-in — three states (one primary action each)

✓
Idle hub: date + greeting ("Ready when you are."), crescent breathing, big "🎙 Speak check-in", quiet secondaries "Log meds" / "Type note", tab bar. Med overlay rides above when a dose is on board.
✓
Listening: live timer (rec dot + 0:14) + ✕ cancel, rotating Fraunces nudge ("What's today been like?"), countdown bar + prompt dots, crescent revolving, single "Stop & save" — no idle buttons.
✓
Saved: checkmark pops, "Captured." + "That's today's check-in. Talk to you next time.", "Done" leads + "🎙 Check in again" secondary. No transcribing UI, no daily card — extraction runs silently.

Type-note — Layout A "signals first"

✓
Nav "Type a check-in" (✕) → glyph pickers are the input (mood/energy/focus, tap to set level) → note field ("Anything you want to remember about today?") → "Save check-in". Same glyph vocabulary as Insights/Edit.

Insights — 5-section snapping scroll

✓
"Insights" (Fraunces) + "today vs your usual" → breakdown (MoodBubbleChart) · signals (glyph ramps) · averages · rhythm · connections. Sleep "not tracked yet." Pinned selector; inactive headers dim.

Calendar — unchanged

✓
Collapsible week↔month grid over the mood/med timeline, exactly as built — owner-preferred, not redesigned. Recordings open from here → detail → Edit sheet.

Recording detail — page top-to-bottom

✓
Navbar ⋯ + date (no back button; swipe-left). Title (Fraunces) + meta → signal glyph summary → Summary card (with ↻ Regenerate) → Meds → Feelings → Transcript → Audio player last → "Edit check-in" (single edit affordance; pencil removed).

Edit sheet (ExtractionReviewView) — one scrolling modal

✓
Header Cancel / "Edit check-in" / Save. Order: 01 When (date/time) · 02 Mood · 03 Energy · 04 Focus (glyph pickers, named 1–5 + synonym) · 05 Sleep (named scale Restless→Deep, no synonyms, 2/4/6/8/10h presets + custom-hours input; bed icon) · 06 Medications · 07 Feelings · 08 Side-effects (chip groups).
✓
Medications: Stimulants only · multi-select · removable (×) · no count limit · each selected med uses P1 inline-expand (dose from table · info-only default time · duration text box defaulted to shortest) · each is an independent MedicationEvent (same timestamp allowed). "Save corrections" writes RecordingTag(.userCorrected) → trains the personal lexicon.
