Your calendar, joined to your journal.
No server involved.

Squirl records the inner day (mood, energy, focus, sleep, meds) from a sub-minute voice check-in. Calendar integration adds the outer day: what was actually on your plate. The join happens entirely on the phone, because iOS already keeps a local copy of every calendar account. The integration itself adds zero network traffic.

The privacy boundary is architectural, not contractual. Calendar data adds no traffic of its own: the only inbound calendar traffic is Apple’s own sync, which exists whether or not Squirl is installed. (Squirl’s sole download is the on-device transcription model, fetched once at setup.) The only outbound path is an export the user triggers and encrypts. Transcription, extraction, capture, storage, and display all run on the phone; there is no Squirl backend to trust, subpoena, or breach.

What gets captured, and what never is

Capture is deliberately skeletal: enough to remember the shape of a day, nothing that profiles the people in it. Classification (“is this a meeting?”) uses attendee presence: deterministic, never guessed from words. Titles off? The context line still reads “3 meetings · 2 events”.

One foundation, four releases

One EventKit foundation, built in Phase 1, carries every later phase. Correlations query the calendar live (nothing extra stored); markers are the only write path. Order is deliberate: plumbing first, the delicate pieces once the plumbing is proven.
