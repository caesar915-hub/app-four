Same spine, eight day cards

Every screen keeps the proven structure — week calendar on top, medication bar, then a list of day cards. The only thing that changes is how each card summarizes a day. Built to the daily-check-in + ADHD guidelines: summary-first, calm, no shame, redundant glyphs, time made visible.

Shared rules across all 8 — calendar never moves (predictability), empty days read neutral not red (no shame), color is never the only cue (shape+hue+fill), timestamps externalize time (time-blindness).
