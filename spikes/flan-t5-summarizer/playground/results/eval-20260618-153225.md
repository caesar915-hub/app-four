## Metric definitions
- **coverage**: % of source content words that appear in summary (higher = more faithful)
- **hallucination**: % of summary content words NOT in source (lower = safer)
- **compression**: input words / summary words (higher = more condensed)
- **med**: medication name recall (e.g. 1/1 if the med survived)
- **sleep**: did the sleep hour value survive?
- **fx**: side-effect recall
- **arc**: if source has mixed positive/negative signal, does summary keep both?
